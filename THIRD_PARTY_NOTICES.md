# Third-party notices

## Anatomy kit

The starter deck vendors a subset of the Anatomy kit to draw its isometric figures:

- `skills/present-to-me/assets/starter/anatomy/kit/iso-kit.mjs`
- `skills/present-to-me/assets/starter/anatomy/kit/lathe.mjs`
- `skills/present-to-me/assets/starter/anatomy/kit/audit.mjs`
- `skills/present-to-me/assets/starter/anatomy/kit/tube.mjs`
- `skills/present-to-me/assets/starter/anatomy/kit/iso.css`

Source: https://github.com/wheresryan22/anatomy. Copyright (c) 2026 Ryan. MIT License. The full licence text is in `skills/present-to-me/assets/starter/anatomy/KIT-LICENSE` and travels with every deck made from the starter.

Anatomy is a complete agent skill for detailed isometric illustration. For figures beyond the simple scenes this starter shows, install and use it directly.

## Typefaces

The starter loads Archivo, IBM Plex Sans and IBM Plex Mono from Google Fonts at run time. They are licensed under the SIL Open Font License 1.1. No font files are stored in this repository. `npm run fonts` downloads them into a deck for offline use. Check each family's licence before redistributing those files.
