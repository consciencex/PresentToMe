# Logos

Put real logos here as `<name>.svg` (or `.png` when the owner publishes no SVG). The build makes each one available two ways:

- in slide HTML: `<img src="assets/logos/<name>.svg" alt="Company">`
- in a drawing made by a hook: `LOGOS.<name>` (a data address for `<image href>`)

Record every file in `SOURCES.md` in this folder when you add it:

| File | From | Date | Terms |
|---|---|---|---|
| acme.svg | https://acme.example/brand | 2026-03-03 | Brand guidelines, use unchanged |

Take a mark from its owner's own brand or press page, use it unchanged, and use it only to refer to that company or product. No third-party logos ship with this starter.
